# WS2812C-2020-V6/W - Worldsemi, addressable RGB LED with integrated driver

Source: `datasheets/WS2812C-2020-V6_W.pdf` (Worldsemi, Chinese edition, 9 pp.); pages read: 1, 2, 3 (p.3 re-read by cir-03)
Package: 2020 four-terminal SMD, 2.20 x 2.00 x 0.84 mm (p.2 Back/Side View), thermal pad: no
Absolute maxima that bind this design: VDD +3.3..+5.3 V; VI -0.3 V..VDD+0.7 V; Topt -40..+85 C (p.2 "最大额定值")

## Pinout
| pin | name | type | note |
|-----|------|------|------|
| 1 | DO | output | data out; DI/DO interchangeable (p.2 table) |
| 2 | GND | ground | signal and supply ground |
| 3 | DI | input | data in |
| 4 | VDD | power | LED + driver supply |

Top view (p.2): DI top-left, GND top-right, VDD bottom-left, DO bottom-right.

## Layout, thermal and decoupling requirements
- PCB Solder Pad (p.2): 0.7 x 0.7 mm pads, 1.13 mm gap between columns (centres +-0.915), 0.40 mm gap between rows (centres +-0.55).
- Model uses EasyEDA C55160508 footprint: same centres, pads 0.9 x 0.7 (0.1 mm longer each end); fabbed on socialbadge rev 2.
- Electrical (p.3, VDD = 5 V): VIH 0.55 VDD min, VIL 0.7 V max; 5 mA per channel (p.1); static current <= 1 uA (p.3).
- Timing (p.3): T0H 220-380 ns, T1H 580 ns-1 us, T0L/T1L 580 ns-1 us, reset low > 280 us; 800 kb/s (p.1).
