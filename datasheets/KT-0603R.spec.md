# KT-0603R - Hubei KENTO, red 0603 LED (charge status)

Source: `datasheets/KT-0603R.pdf` (spec for approval Rev A.0, 2018-12-06); pages read: 2, 3
Package: 0603, 1.6 x 0.8 x 0.6 mm, thermal pad: no (p.2)
