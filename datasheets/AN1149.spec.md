# AN1149 - Microchip, Li-Ion charger + system/battery load sharing (application note)

Source: `datasheets/AN1149.pdf` (DS01149C, 2008), from ww1.microchip.com/downloads/en/AppNotes/01149c.pdf; pages read: 2, 5, 6
Not a part: records the load-sharing power-path topology used in cir-01 (`proximity_fear/circuits/power.py`, `PowerPath`).

## Topology (Fig 2 p.2; Figs 5-7 p.5-6)
| element | connection | role | page |
|---------|-----------|------|------|
| D1 Schottky | anode on input (VBUS), cathode on system load | blocks reverse current into the source; IF(AV) > max system load | p.6 "Selecting The Diode" |
| Q1 P-ch MOSFET | between battery + and system load; body diode toward the load; gate on the input source | battery feeds the load only when the input is absent | p.5 "Selecting The MOSFET", Figs 6-7 |
| R_PULL | gate to GND, 100 kOhm (~50 uA at 5 V) | turns Q1 on when the input is removed | p.5 "Selecting The Pull-Down Resistor" |

Behaviour (p.5): input present -> gate high -> Q1 off, the source feeds the load while the charger charges the cell (load is not on the charger output, so termination works); input absent -> R_PULL pulls the gate to 0 -> Q1 on, cell feeds the load. Note on p.5: choose Q1's gate threshold so it turns on at the lowest cell voltage.

## Application in this design
- D1 = SS14, Q1 = AO3401A (drain VBAT, source SYS; VGS(th) -0.5..-1.3 V, RDS(on) <= 85 mOhm at -2.5 V, AO3401A spec note), R_PULL = 10 kOhm (A-08, Phase 3b: VBUS discharge tau <= 95 ms instead of 0.95 s; 0.5 mA / 2.5 mW at 5 V), also the VBUS bleed. The LED switch is on SYS, never on VBAT (p.5 "Connecting the system load to the battery").
- Off-check with USB: VGS = VF(SS14) >= 0. Body diode: SYS >= 4.75 - 0.55 = 4.20 V vs VBAT <= 4.232 V (MCP73831 VREG max) -> at most 0.03 V forward, below VSD ~0.7 V.
- On battery: drop <= 13 mV at 150 mA; 3V3 regulated down to VBAT ~3.4-3.5 V (AP2112K dropout).
